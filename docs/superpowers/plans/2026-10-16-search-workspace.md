# 查询日志阅读工作区实施计划

**目标：** 将已确认的紧凑查询栏、配置抽屉、可调节双栏结果和专注阅读方案落地。

**架构：** App 管理连接配置与范围抽屉；SearchPanel 保留现有查询与归档逻辑，压缩查询栏；SearchResults 独立管理命中列表、上下文与阅读工具。仅改变前端，不改变查询协议。

**技术：** React 19、TypeScript、Tailwind、现有 Tauri API。

- [x] App 与 ServerConfig：查询模式移除常驻配置区，配置通过抽屉打开，抽屉内部滚动。
- [x] SearchPanel：紧凑查询栏、高级条件折叠、独立进度栏、查询范围入口。
- [x] SearchResults：双栏、拖拽和键盘调整、命中导航、行号与高亮、复制、字号、换行、专注阅读。
- [x] 保留阅读偏好与滚动位置；小窗口不挤压阅读区。
- [x] 浏览器验证：默认窗口及最小窗口的布局、抽屉与高级条件、使用样例命中验证阅读交互。
